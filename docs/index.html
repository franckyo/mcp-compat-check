Will Claude, Cursor and ChatGPT connect to your MCP server?

A free, open-source check of your own MCP server, done the way these clients connect: protocol version, OAuth sign-in and tool definitions. Results in plain language, in a few seconds.

npx mcp-compat-check https://mcp.yourcompany.com/mcp

Needs Node.js 20 or newer. Add --json for machine-readable output (handy in CI). Source: github.com/franckyo/mcp-compat-check (MIT).

What gets checked

  • Current spec (2026-07-28): whether clients that open with the new handshake can connect directly.
  • Protocol negotiation: the version your server agrees on and whether it handles newer clients.
  • OAuth sign-in: the discovery documents Claude.ai, ChatGPT and Cursor read, including the server-URL mismatch that makes Cursor refuse to log in, PKCE, and self-registration.
  • Tools: valid JSON Schemas, names and duplicates, the things that make clients drop tools or the whole server.
  • Sessions: servers that reject their own session (common behind load balancers).

What it never does

It never calls tools, sends credentials, changes data or follows redirects, and it never connects to private or internal addresses (every DNS answer is checked at connect time). Only the standard client handshake is used. Run it on servers you own or operate.
